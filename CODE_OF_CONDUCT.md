# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

All participants in this project are expected to abide by its terms.

## Reporting

Report violations privately to `iamgayan@gmail.com`. Reports are confidential.

The maintainer responds within seven days and follows the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) from the Contributor Covenant for consequences.
